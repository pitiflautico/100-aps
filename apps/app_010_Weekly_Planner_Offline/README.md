# Weekly Planner Offline

> Plan and track tasks for each day of the week

## Features

- 📅 **7 Days View**: Switch between Mon-Sun with task count badges
- ✅ **Task Management**: Add, complete, delete tasks per day
- 📊 **Week Overview**: Total and completed tasks for the whole week
- 🗑️ **Long Press Delete**: Hold task to remove it
- 💾 **AsyncStorage**: All weekly data persisted
- 💰 **AdMob**: Banner ads + Interstitial every 10 actions

## Tech Stack

- React Native 0.81.5 + TypeScript
- AsyncStorage ^2.2.0
- AdMob v14.3.0
