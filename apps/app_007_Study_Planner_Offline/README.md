# Study Planner Offline

> Organize your study tasks with categories, priorities, and smart filtering

## Features

- ✅ **Task Management**: Add, complete, delete tasks with long-press
- 📚 **5 Categories**: Study, Assignment, Exam, Reading, Other
- 🎯 **3 Priority Levels**: Low, Medium, High (color-coded)
- 🔍 **Smart Filters**: View All, Active, or Completed tasks
- 💾 **AsyncStorage**: All tasks persisted locally
- 📊 **Live Stats**: Active and completed task counts
- 💰 **AdMob**: Banner ads + Interstitial every 10 tasks
- 🎨 **Modern UI**: FAB button, modal for adding tasks

## Tech Stack

- React Native 0.81.5 + TypeScript
- AsyncStorage ^2.2.0
- AdMob v14.3.0
