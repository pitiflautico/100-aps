# Daily Routine Planner

> Track and complete your daily routine tasks with progress tracking

## Features

- ✅ **9 Default Tasks**: Pre-loaded daily routine from 6 AM to 10 PM
- ➕ **Add Custom Tasks**: Create new routine items with time + task
- 📊 **Progress Tracking**: Real-time completion percentage
- 🔄 **Reset Day**: Clear all completions to start fresh
- 💾 **AsyncStorage**: Routine persisted locally
- 💰 **AdMob**: Banner ads + Interstitial every 8 task toggles

## Tech Stack

- React Native 0.81.5 + TypeScript
- AsyncStorage ^2.2.0
- AdMob v14.3.0
