# Habit Tracker Pro

> Build and track daily habits with streaks and completion rates

## Features

- ✅ **Custom Habits**: Create habits with icons and colors
- 🎯 **6 Preset Habits**: Quick-start with Exercise, Read, Meditate, etc.
- 🔥 **Streak Tracking**: Daily streak counter for each habit
- 📊 **Completion Rate**: Today's overall completion percentage
- 💾 **AsyncStorage**: Habits and daily logs persisted
- 🎨 **Customization**: 12 icons and 6 colors to choose from
- 💰 **AdMob**: Banner ads + Interstitial every 7 habit checks
- 📅 **Daily Tracking**: Check/uncheck habits for today

## Tech Stack

- React Native 0.81.5 + TypeScript
- AsyncStorage ^2.2.0
- AdMob v14.3.0
