# Flashcards Trainer Offline

> Study flashcards offline with multiple decks

## Features
- Create and study flashcard decks
- Track correct/incorrect answers
- Multiple pre-loaded decks (Spanish, Math)
- Offline storage with AsyncStorage
- Score tracking per session

## Usage
1. Select a deck from the list
2. Tap cards to flip and reveal answer
3. Mark as correct or incorrect
4. Review session results

## Tech Stack
- React Native + Expo
- TypeScript
- AsyncStorage for persistence
- AdMob integration (shared module)

## Installation
```bash
npm install
npm start
```
